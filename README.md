AI Resume Job Recommendation System

An AI-powered Resume Job Recommendation System that analyzes candidate resumes and recommends relevant job opportunities based on skills, experience, qualifications, and job requirements.

📌 Project Overview

The AI Resume Job Recommendation System is designed to simplify the job-search process by automatically analyzing resume information and matching candidates with suitable job opportunities.

The system uses Natural Language Processing (NLP) and Machine Learning techniques to extract relevant information from resumes and identify job roles that best match the candidate's profile.

🎯 Objectives

- Analyze resumes automatically.
- Extract relevant skills, qualifications, and experience.
- Match candidate profiles with suitable job opportunities.
- Recommend relevant job roles based on resume information.
- Identify skill gaps between candidates and recommended jobs.
- Improve the efficiency of the job recommendation process.

⚙️ How to Run

1. Clone the Repository

git clone <your-github-repository-url>

2. Navigate to the Project Folder

cd AI-Resume-Job-Recommendation

3. Install Required Dependencies

pip install -r requirements.txt

4. Run the Application

python app.py

5. Open in Browser

Open the local Flask URL displayed in the terminal, usually:

http://127.0.0.1:5000/
